Подключение к GitHub

Данные трекера хранятся в файле data.json в репозитории , чтобы синхронизироваться между устройствами. Нужно один раз вставить токен на каждом устройстве/браузере — он сохраняется только здесь и никуда, кроме GitHub API, не отправляется.

Получить токен на GitHub →

На странице GitHub останется только выбрать репозиторий в поле «Selected repositories» и нажать «Generate token» — остальное уже заполнено.
